# Generate AI Videos for FREE with Claude Code + Google Veo 3

Turn Claude Code into a video generator. It calls **Google Veo 3** on Vertex AI to make real MP4
clips **with sound** — billed to your Google Cloud project, so a new account's **$300 free credit**
pays for it (≈ **200+ short clips**). Cancel the pricey subscriptions.

> Unofficial setup. You call Google's Veo API with **your own Google login (ADC)** — no third-party
> keys, no proxy. Just Claude Code + a bundled skill.

## What you get

Say *"generate an 8-second cinematic video of a fox running through snow"* in Claude Code → a real
`.mp4` (video **and** audio) appears, generated by Veo 3.1, paid from your Google credit.

## Setup (once)

**You do — browser / payment (can't be automated):**
1. Create a Google account → [console.cloud.google.com](https://console.cloud.google.com) → **claim the
   $300 free trial** and add a billing card. *Not charged during the trial* — it's verification. Vertex
   has **no free tier**, so billing is required.
2. Install [Claude Code](https://claude.com/claude-code), the
   [gcloud CLI](https://cloud.google.com/sdk/docs/install), and Python 3.

**Then — Claude / the scripts do the rest:**
```bash
git clone https://github.com/Itsme23476/claude-code-veo-video && cd claude-code-veo-video
./connect-vertex.sh     # ADC login + create project + enable Vertex (you approve the browser)
./install.sh            # installs the "veo-video" skill into ~/.claude/skills
```
Now open Claude Code and say: **"generate a video of a golden retriever puppy running on a beach"**.

## Models & cost

Veo bills **per second** (~$0.15/s fast → ~$0.40/s standard, audio included). ~**$1.20 for an 8s fast
clip** → **$300 ≈ 200+ clips**. Default model `veo-3.1-fast-generate-001`; see
[SKILL.md](skills/veo-video/SKILL.md) for the full list (lite / fast / standard, Veo 3.0 & 3.1) and
options (duration, `9:16` for Shorts, 1080p, multiple samples).

## How it works

`skills/veo-video/generate_veo.py` submits a Veo `predictLongRunning` job to Vertex, polls until done,
and downloads the MP4 — authed with your **ADC token** (same Google login, no API keys). `SKILL.md`
tells Claude Code when and how to run it, so you just describe the video in plain language.
